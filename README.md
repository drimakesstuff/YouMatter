# YouMatter: Counselor Appointment System 💙

A comforting Flask web app that helps students book counseling appointments and explore emotional support pages — because you matter. 🌿💬

---

## 🚀 Features
- 📅 Book appointments (stored locally in Excel)
- 💬 Explore emotion-based support pages (sad, angry, anxious, happy, calm, tired)
- ⚡ Prevents double bookings for the same slot
- 🧠 Simple and easy-to-use interface for students

---

## 🛠️ Tech Stack
- **Python** with **Flask** (web framework)
- **OpenPyXL** (Excel file management)
- **HTML/CSS** with Jinja2 templates

---

## 💻 Installation & Run Locally
1. **Clone the repository:**
```bash
git clone https://github.com/drimakesstuff/YouMatter.git
```
2. **Go into the project folder**:

```bash
cd YouMatter
```
3. **Install dependencies**:

```bash
pip install -r requirements.txt
```
4. **Run the app**:

```bash
python app.py
```
5. **Open in browser**:
Visit [http://127.0.0.1:5000](http://127.0.0.1:5000)

The app will automatically create bookings.xlsx if it doesn’t exist.
